# PostgreSQL

## Локальный запуск

1. Установите зависимости командой `npm ci`.
2. Скопируйте [.env.example](.env.example) в `.env` командой `cp -n .env.example .env`. Если у вас уже есть `.env`, отредактируйте его.
3. Укажите в `PGPASSWORD` действующий пароль пользователя PostgreSQL из `PGUSER`. По умолчанию это пользователь `postgres`. Пример рассчитан на базу `node_api` на `localhost:5432`. Если параметры вашей базы отличаются, измените их в `.env`.

   `dotenv` загружает `.env` в `process.env` при запуске приложения. `.env` исключён из Git.

4. Запустите приложение командой `node index.js`. При успешном подключении появится сообщение `Connected to PostgreSQL`.
