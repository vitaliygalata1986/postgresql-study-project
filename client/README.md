# Клиент постов

React-клиент показывает, создаёт, редактирует и удаляет посты через Express API из каталога `server/`.

## Локальный запуск

Команды проверены на Node.js 24.

1. Запустите PostgreSQL и Express по инструкции в [корневом README](../README.md#локальный-запуск).
2. В другом терминале перейдите в каталог `client/`, скопируйте [.env.example](.env.example) в `.env`, установите зависимости и запустите Vite. Если `.env` уже существует, команда копирования его сохранит.

   ```sh
   cp -n .env.example .env
   npm ci
   npm run dev
   ```

3. Откройте `http://localhost:5173` или другой адрес, который выведет Vite.

Vite читает адрес Express из `POSTS_API_TARGET` в `client/.env` и по умолчанию использует `http://127.0.0.1:3000`. Переменная в окружении процесса Vite имеет приоритет над файлом. Прокси убирает префикс `/api`, поэтому клиентский `GET /api/` становится `GET /` на сервере.

`client/.env` исключён из Git. Настройки подключения PostgreSQL задаются в `server/.env`.

## Проверки и сборка

Из каталога `client/` выполните `npm run lint` и `npm run build`. Команда `npm run preview` открывает собранный клиент локально с тем же прокси. При размещении сборки на другом хостинге настройте обратный прокси для `/api/` по тому же правилу.
