# Клиент постов

React-клиент показывает, создаёт, редактирует и удаляет посты через Express API из каталога `server/`.

## Локальный запуск

Команды проверены на Node.js 24.

1. Запустите PostgreSQL и Express по инструкции в [корневом README](../README.md#локальный-запуск).
2. В другом терминале перейдите в каталог `client/`, установите зависимости и запустите Vite.

   ```sh
   npm ci
   npm run dev
   ```

3. Откройте `http://localhost:5173` или другой адрес, который выведет Vite.

Vite перенаправляет запросы с префиксом `/api/` на Express (`http://127.0.0.1:3000`) и убирает префикс `/api`. Например, клиентский `GET /api/` становится `GET /` на сервере. Если Express запущен на другом адресе, задайте `POSTS_API_TARGET` в окружении процесса Vite. Настройки PostgreSQL задаются в `server/.env`.

## Проверки и сборка

Из каталога `client/` выполните `npm run lint` и `npm run build`. Команда `npm run preview` открывает собранный клиент локально с тем же прокси. При размещении сборки на другом хостинге настройте обратный прокси для `/api/` по тому же правилу.
